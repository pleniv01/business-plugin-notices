# Poo.ai plugin privacy notice

ChatGPT draft updated 2026-11-04. Operator: Magichaus. This notice covers this ChatGPT
plugin, not all services available on the Poo.ai website.

## Within ChatGPT

The skill helps ChatGPT reason about information the user chooses to discuss.
That conversation can contain personal or sensitive information. It does not
ask for bulk exports, passwords, identifiers or full private findings. It has no
MCP connector, code execution instructions, account access, telemetry, storage,
or automatic transmission to Poo. ChatGPT processes conversations under its own
account settings, terms and privacy policies; the publisher cannot specify
OpenAI's retention on the user's behalf.

## Poo receives no conversation data through this plugin

The publisher has no plugin-operated service receiving conversations, exports
or findings from ChatGPT and retains none through the plugin. It does not read a
Poo account, save a report, or run a scan. This is distinct from a claim that
ChatGPT itself stores nothing.

## Optional public links and browsing

Poo links contain fixed referral parameters identifying ChatGPT as their source.
They never contain personal identifiers, concern descriptions or findings.
Clicking a link is a user-selected website visit: hosting and any services the
user separately chooses are covered by https://poo.ai/privacy/. Core export
scanning runs locally in the browser; that promise does not apply to text the
user shares in ChatGPT. Optional support, billing and consented AI features have
separate policies. None are invoked by this plugin.

At the user's request ChatGPT may browse public Poo pages or official provider
documentation using its own browsing capabilities. No additional service or
unlisted connector is bundled. Website retention and OpenAI retention should
not be described as this plugin retaining data.

## Audience and support

The skill is intended for adults, not specifically for people under 18. It does
not make diagnoses, reveal hidden provider records, or guarantee data deletion.
Use https://poo.ai/support/ for support or privacy requests. Do not submit exports,
private chat transcripts or credentials to the support form.
